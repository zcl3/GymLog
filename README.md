# 燃刻（GymLog）

燃刻是一款面向个人使用的 Android 健身记录 App，用于记录训练、饮食和饮水，并按日期查看每天的完整情况。

## 当前版本

- 版本名称：`1.2`
- 版本号：`3`
- 应用包名：`com.personal.gymlog`
- 当前分支：`main`

## 主要功能

### 首页

- 展示当前选择日期的训练、饮食和饮水记录。
- 训练记录显示训练时间、动作、重量和次数。
- 饮食记录显示热量、蛋白质、碳水和脂肪合计。
- 饮水记录显示当日饮水量与目标值。

### 训练

- 从动作库添加训练动作。
- 记录每组重量、次数和完成状态。
- 提供组间休息倒计时。
- 查看当前日期的训练历史、动作和组明细。
- 支持删除整次训练记录，相关动作和组数据会一并删除。

### 饮食

- 支持早餐、午餐、晚餐和加餐。
- 记录食物名称、热量、蛋白质、碳水和脂肪。
- 支持编辑和删除饮食记录。

### 饮水

- 快捷记录常用饮水量，也可以输入自定义毫升数。
- 支持修改每日饮水目标。
- 支持删除单条饮水记录。

### 更多

- 选择要查看和记录的年月日。
- 设置每日饮水目标、默认组间休息和字体大小。
- 查看统计数据、训练历史、动作库和训练模板。

- Jetpack Compose / Material 3
- Room
- DataStore Preferences
- WorkManager
- Navigation Compose

## 本地构建

在项目根目录执行：

```text
gradlew.bat testDebugUnitTest assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。发布用 APK 位于本地 `releases/燃刻-v1.1.apk`，APK 文件默认被 Git 忽略。
